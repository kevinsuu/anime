# 我的清單效能

`/list` 的首屏只等待目前分頁的清單項目；觀看數、收藏分類與標籤會在首屏
渲染後以非阻塞請求補上。這讓篩選與分頁的核心內容不會受輔助資料影響。

首次進入清單時使用頁面內 skeleton，不再以全螢幕遮罩鎖住導覽與版面；重新
查詢期間保留目前已顯示的項目，只有請求成功後才替換資料，避免篩選或分頁時
整頁閃空。

清單列的動畫連結停用 Nuxt 預取，避免一個 50 筆頁面同時發出 50 個詳情頁
`_payload.json` 請求。封面則由共享的 IntersectionObserver 在進入視窗附近後才
設定 `src`，只讓可見內容競爭網路頻寬。

資料庫以 `user_id` 為起點的複合索引支援「最近加入」排序與觀看狀態篩選：
`(user_id, created_at, id)` 與 `(user_id, watched, id)`。部署時須執行 Laravel
migration，才能取得索引的查詢效益。

清單新增 API 可在建立項目時帶入 `watched`；卡片將未收藏作品標記為已觀看時
直接使用這個欄位，避免先建立收藏再發出第二個更新請求。

目錄與季番頁的作品資料和登入者狀態分開處理：作品先顯示，`meBootstrap` 在
背景補上收藏/觀看標記，避免狀態同步延後首屏。同步期間仍可收藏或標記已觀看，
分類操作則等清單項目 ID 可用後才開放。

目錄與季番頁的首屏圖片會先掛載並立即開始請求，但在前四張首屏圖片完成、載入失敗
或確認沒有封面前，維持圖片 skeleton 遮罩；完成後一次顯示完整卡片，避免使用者看到
「卡片資料已出現、封面仍是灰色」的中間狀態。首屏以外的圖片仍由共享的
`IntersectionObserver` 延遲載入。
